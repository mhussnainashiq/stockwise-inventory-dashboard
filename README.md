# StockWise — Inventory & Warehouse Management

Professional inventory dashboard built with React and Vite.

## Features

- Dashboard with inventory valuation, low-stock KPIs, charts
- Products CRUD (SKU, cost, price, reorder levels)
- Categories and Warehouses
- Stock movements with negative-stock prevention
- Suppliers management
- Purchase orders and goods receiving (updates stock)
- Low-stock alerts
- Printable stock reports and CSV export
- Light/dark themes, LocalStorage persistence, responsive layout

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

React 18, Vite, React Router, Lucide React, Recharts, custom CSS, LocalStorage
